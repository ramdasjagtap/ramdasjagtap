### 🔭 Currently

Building a **single-cycle RV32I RISC-V CPU** that runs all 37 base instructions and
passes a self-checking testbench. A benchmarking flow measures CPI, Fmax, critical path,
area and power on a Xilinx Artix-7, an Intel Cyclone IV and sky130 standard cells.

| [**CPU**](https://github.com/ramdasjagtap/CPU) | RISC-V processor in Verilog: PC, register file, ALU and ALU control, immediate generator, control unit, instruction and data memory |
